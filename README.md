# claude-skills

My Claude Code skills.

## To deploy

```bash
git clone https://github.com/andreas-edstart/claude-skills.git ~/.claude-skills
~/.claude-skills/bootstrap
```

Each skill is symlinked into `~/.claude/skills`. A skill you already have with the same name is left alone.

## Adding a skill

Create it in `~/.claude-skills`, then re-run `bootstrap`.
